# File Sorter

A utility to organize files into folders based on their extensions.

## Features

- **Automatic Sorting**: Moves files into category folders (Images, Docs, Media, etc.)
- **Customizable**: Works on any selected directory
- **Progress Tracking**: Shows sorting progress
- **Modern UI**: Dark theme interface

## Usage

```bash
python FileSorter.py
```

1. Select the folder you want to sort
2. Click "Sort Files"
3. Files will be organized into subfolders

## Categories

- **Images**: jpg, jpeg, png, gif, bmp
- **Documents**: pdf, doc, docx, txt, xls, ppt
- **Audio**: mp3, wav, flac
- **Video**: mp4, mkv, avi
- **Archives**: zip, rar, 7z

## Requirements

- Python 3.6+
- tkinter (built-in)
