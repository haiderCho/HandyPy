# Translator

A multi-language translation tool built with Python and Tkinter.

## Features

- **Multi-language Support**: Translates between 90+ languages
- **Auto-detection**: Automatically detects source language
- **Modern API**: Uses `deep-translator` (Google Translate)
- **UI**: Simple interface with source and target text areas

## Usage

```bash
python translator.py
```

1. Select target language
2. Type text in the left box
3. Click "Translate"
4. View result in the right box

## Requirements

- Python 3.6+
- deep-translator
- tkinter (built-in)
