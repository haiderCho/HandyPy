# Calendar

## Features

* Displays a full year calendar in a clean, readable layout.
* Input validation for year entry.
* Modernized interface using `ttk` widgets.
* Opens calendar in a separate window for clarity.

## Requirements

* Python 3.x
* Tkinter (bundled with standard Python installations)

## Usage

1. Run the script.
2. Enter a valid year in the input field.
3. Select **Show Calendar** to generate the yearly calendar.
4. Close the application using the **Close** button.
