# Advanced Notepad

A feature-rich text editor built with Python and Tkinter.

## Features

- **File Operations**: New, Open, Save, Save As
- **Editing**: Cut, Copy, Paste, Undo, Redo
- **Search Tools**: 
  - Find text
  - Find and Replace
- **View Options**:
  - Word Count statistics
  - Font Selection (Family and Size)
- **UI**: Clean interface with status bar and scrollbars

## Usage

```bash
python Notepad.py
```

## Shortcuts

- `Ctrl+N`: New File
- `Ctrl+O`: Open File
- `Ctrl+S`: Save File
- `Ctrl+X/C/V`: Cut/Copy/Paste
- `Ctrl+F`: Find

## Requirements

- Python 3.6+
- tkinter (built-in)
