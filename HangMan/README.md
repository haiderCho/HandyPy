# Hangman

A classic Hangman word guessing game.

## Features

- **Gameplay**: Guess letters to reveal the hidden word
- **Visuals**: Graphical representation of the hangman
- **Word Bank**: Randomly selects words from a list
- **UI**: Interactive game interface

## Usage

```bash
python Hangman.py
```

## Requirements

- Python 3.6+
- tkinter (built-in)
