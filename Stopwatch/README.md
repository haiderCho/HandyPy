# Stopwatch

A precise stopwatch application.

## Features

- **Timing**: Hours, Minutes, Seconds, Milliseconds
- **Controls**: Start, Stop, Reset
- **Laps**: Record lap times
- **UI**: Large, easy-to-read display

## Usage

```bash
python Stopwatch.py
```

## Requirements

- Python 3.6+
- tkinter (built-in)
