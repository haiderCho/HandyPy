# Password Generator

A secure password generator with customizable options.

## Features

- **Customizable Length**: Choose password length (8-32 chars)
- **Character Sets**: Include/exclude Uppercase, Lowercase, Numbers, Symbols
- **Strength Indicator**: Visual feedback on password strength
- **Clipboard**: One-click copy to clipboard
- **Secure**: Uses Python's `secrets` module for cryptographic security

## Usage

```bash
python PasswordGenerator.py
```

## Requirements

- Python 3.6+
- tkinter (built-in)
- pyperclip (optional, for clipboard)
