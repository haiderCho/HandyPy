# QR Code Generator

A tool to generate and save QR codes.

## Features

- **Custom Content**: Generate QR codes for URLs, text, Wi-Fi, etc.
- **Customization**:
  - Foreground/Background colors
  - Box size and border
  - Error correction level
- **Preview**: Live preview of generated QR code
- **Save**: Export as PNG image

## Usage

```bash
python QRCodeGenerator.py
```

1. Enter text or URL
2. Adjust settings (optional)
3. Click "Generate"
4. Click "Save" to export

## Requirements

- Python 3.6+
- qrcode
- Pillow
- tkinter (built-in)
