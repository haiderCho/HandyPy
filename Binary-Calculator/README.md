# Binary Calculator

A calculator for binary arithmetic and conversions.

## Features

- **Binary Operations**: Addition (+), Subtraction (-), Multiplication (X), Division (/)
- **Conversions**: 
  - Binary to Decimal
  - Decimal to Binary
- **UI**: Calculator-style layout with dedicated binary keys
- **Error Handling**: Handles division by zero and invalid inputs

## Usage

```bash
python script.py
```

## Operations

- **Bin→Dec**: Convert current binary input to decimal
- **Dec→Bin**: Convert current decimal input to binary
- **Standard Math**: Perform operations on binary numbers directly

## Requirements

- Python 3.6+
- tkinter (built-in)
