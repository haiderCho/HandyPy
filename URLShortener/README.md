# URL Shortener

A tool to shorten long URLs using TinyURL service.

## Features

- **Shortening**: Convert long URLs to short TinyURL links
- **Validation**: Checks if input URL is valid
- **Clipboard**: Auto-copy or one-click copy to clipboard
- **Error Handling**: Handles network errors and invalid URLs gracefully

## Usage

```bash
python URLShortener.py
```

1. Paste long URL
2. Click "Shorten"
3. Copy the result

## Requirements

- Python 3.6+
- pyshorteners
- pyperclip
- tkinter (built-in)
