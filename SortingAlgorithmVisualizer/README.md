# Sorting Algorithm Visualizer

A tool to visualize how sorting algorithms work.

## Features

- **Algorithms**: Bubble Sort, Merge Sort, Quick Sort, etc.
- **Visualization**: Real-time graphical representation of sorting
- **Controls**: Start, Stop, Reset, Speed control
- **Random Data**: Generates new datasets for visualization

## Usage

```bash
python SortingAlgorithmVisualizer.py
```

## Requirements

- Python 3.6+
- tkinter (built-in)
